# Data Analysis of IMDb Movie Dataset

**Notebook:** [data_analysis_imdb_movie_dataset.ipynb](data_analysis_imdb_movie_dataset.ipynb)
**Data:** `IMDB-Movie-Data (2).csv` (1,000 movies: Rank, Title, Genre, Description, Director, Actors, Year, Runtime, Rating, Votes, Revenue, Metascore)

## Questions answered
- Top and last rows, shape, info, null values (Revenue and Metascore have gaps), duplicates, summary statistics
- Movies with runtime of 180 minutes or more; top 10 lengthiest movies
- Year with the highest votes and the highest revenue
- Average rating for each director and year-wise
- Number of movies per year
- Most popular movie (highest revenue); top 10 highest-rated and highest-revenue movies
- Rating vs revenue relationship (scatter plot, correlation heatmap), pivot tables
