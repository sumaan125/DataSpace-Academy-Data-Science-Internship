# Python Basics

**Notebook:** [python_basic.ipynb](python_basic.ipynb)

Introduction to core Python, the foundation for all later work.

## Topics Covered
- Operators and data types
- Strings: indexing, slicing, built-in functions
- Lists: concatenation, repetition, nested lists, built-in functions
- Tuples: immutability, indexing/slicing, loops, concatenation/repetition
- Dictionaries: `keys`, `values`, `items`, `get`, `copy`, `clear`, `pop`, `popitem`
- Sets and their built-in functions
- Conditional statements: `if` / `elif` / `else`, nested conditions
- Iteration: loops and `range`
