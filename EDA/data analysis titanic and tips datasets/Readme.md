# Data Analysis of Titanic and Tips Datasets

**Notebook:** [data_analysis_Titanic_and_Tips_dataset.ipynb](data_analysis_Titanic_and_Tips_dataset.ipynb)
**Data:** `train (4).csv` (Titanic, 891 passengers: PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked). The Tips dataset is loaded from Seaborn.

## What was done
- NumPy and Pandas basics: vectors/matrices, axis operations, Series and DataFrames
- Inspection: `head`, `tail`, `sample`, `shape`, `info`, `describe`
- Data quality: missing values (count and percentage), duplicates, renaming
- Categorical encoding
- Univariate analysis: numerical and categorical (histogram, box plot, pie, bar, count plot)
- Bivariate analysis: numerical vs numerical, categorical vs numerical, categorical vs categorical (scatter plots, box plots, heatmaps)
- Visualisation with Matplotlib, Seaborn and Pandas plotting
