# Data Analysis of Chocolate Portfolio Project and Flight Datasets

**Notebook:** [data_analysis_Chocolate_Protfolio_Project_and_Flight_dataset.ipynb](data_analysis_Chocolate_Protfolio_Project_and_Flight_dataset.ipynb)
**Data:** `choclate protfolio project - 11.xlsx` (chocolate sales). The Flights dataset is loaded from Seaborn.

## What was done
- Loading Excel data with `pd.read_excel`
- Sales analysis using Pandas pivot tables
- Flights dataset: passenger-trend analysis visualised with Seaborn heatmaps
